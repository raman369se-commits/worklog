# WORKLOG

Mobile-first offline work & income tracker — PWA for iPhone.

Personal, local-first PWA for logging jobs, working hours, breaks, photos, income and payments.

## Stack
- Static HTML/CSS/JavaScript
- IndexedDB for local storage
- Service Worker for offline caching
- GitHub Pages hosting

## MVP
Today, active timer, lunch/resume, work history, calendar, money by currency, hourly/fixed pay, photos, status, backup/restore.

No authentication and no server-side user data.
